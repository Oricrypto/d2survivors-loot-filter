## Filtro de loot para D2 Survivors v1.22.0 (pré-lançamento)

Filtro de loot para a versão Windows do D2 Survivors: 53 builds de itens (7 classes), builds próprias, uniques à mão, venda automática opcional (começa desligada, em modo de teste).

**Arquivo:** `Filtro-D2Survivors-v1.22.0.zip` (31.8 MB)

**SHA-256:** `a3df0156d5df4015220dfac62266d671c5803352d4da507dde874e3324989225`

Para conferir: `certutil -hashfile Filtro-D2Survivors-v1.22.0.zip SHA256`

### Como instalar
1. Instale o jogo para Windows e feche-o.
2. Descompacte o zip (pode ser dentro da pasta do jogo) e dê dois cliques em `INSTALAR.bat`.
3. No jogo: ESC, FILTER. Leia o `LEIA-ME.txt` antes de ligar a venda automática.

### Antes de usar
- Pré-lançamento: testado numa pasta de jogo simulada e no jogo do autor, ainda não por outras pessoas num jogo de verdade.
- Ferramenta não oficial de fã, sem garantia. Ela modifica o `app.asar` do jogo (o original é guardado e o `desinstalar.bat` o devolve). Faça backup do save antes de ligar a venda automática.
- Só Windows e só o jogo instalado (não funciona no navegador, nem no Mac ou Linux).
- Os scripts não são assinados: o Windows ou o antivírus podem avisar. O código dos `.bat` está legível no repositório, na pasta `fonte/`.
- O painel dentro do jogo está em inglês.

*English: loot filter for the Windows desktop version of D2 Survivors. Unofficial fan tool, no warranty, pre-release. Download the zip, run `INSTALAR.bat`, then ESC → FILTER in the game. Test mode by default.*
