### Português
Filtro de loot para a versão Windows do D2 Survivors: 53 builds de itens (7 classes), builds próprias, uniques à mão, venda automática opcional (começa desligada, em modo de teste).

1. Instale o jogo para Windows e feche-o.
2. Descompacte o zip (pode ser dentro da pasta do jogo) e dê dois cliques em `INSTALAR.bat` (mensagens em português e inglês).
3. No jogo: ESC, FILTER. Leia o `LEIA-ME.txt` antes de ligar a venda automática.

- Pré-lançamento: o filtro em si já roda no jogo do autor, mas este instalador só foi testado numa pasta de jogo simulada, ainda não num jogo de verdade.
- Ferramenta não oficial de fã, sem garantia. Ela modifica o `app.asar` do jogo (o original é guardado e o `desinstalar.bat` o devolve). Faça backup do save antes de ligar a venda automática.
- Só Windows e só o jogo instalado (não funciona no navegador, nem no Mac ou Linux).
- Os scripts não são assinados: o Windows ou o antivírus podem avisar. O código dos `.bat` está legível no repositório, na pasta `fonte/`.

### English
Loot filter for the Windows desktop version of D2 Survivors: 53 item builds (7 classes), your own builds, hand-picked uniques, optional auto-sell (starts off, in test mode).

1. Install the Windows game and close it.
2. Unzip (it can be inside the game's folder) and double-click `INSTALAR.bat` (messages in Portuguese and English).
3. In the game: ESC, FILTER. Read `README-EN.txt` before turning auto-sell on.

- Pre-release: the filter itself runs on the author's game, but this installer has only been tested on a simulated game folder, not on a real game yet.
- Unofficial fan tool, no warranty. It modifies the game's `app.asar` (the original is kept and `desinstalar.bat` gives it back). Back up your save before turning auto-sell on.
- Windows only, installed game only (not the browser version, not Mac or Linux).
- The scripts are not signed: Windows or your antivirus may warn. The `.bat` source is readable in the repository, folder `fonte/`.
- The in-game panel is in English.
